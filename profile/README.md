# dhis2-utils

Welcome to the dhis2-utils GitHub organization - a collection of tools and utilities for DHIS2 Implementations.

## Getting started

If you're looking for a specific project, browse the repositories in this organization or check the organization documentation for more details.

## Project maturity

The tools here are in various stages of maturity. Many may not be intended for public use. They do not go through the same level of testing and QA as the DHIS2 platform and core apps. Please pay attention to the maturity levels indicated on individual repositories.

| Level | Badge | Meaning |
| --- | --- | --- |
| Experimental | ![Maturity: Experimental](https://img.shields.io/badge/maturity-Experimental-orange) | Exploratory; expect rough edges and breaking changes. |
| Validated | ![Maturity: Validated](https://img.shields.io/badge/maturity-Validated-yellow) | Tested and used successfully for real work, but in limited contexts. |
| Stable | ![Maturity: Stable](https://img.shields.io/badge/maturity-Stable-dodgerblue) | Used across multiple contexts with a reasonably stable interface. |
| Deprecated | ![Status: Deprecated](https://img.shields.io/badge/status-Deprecated-red) | No longer recommended for new use; see the repository for migration guidance. |
